# Dream-to-achievers

Dream to Achievers is a high-performance commerce and partner distribution platform with 4-tier milestone rewards, wholesale product catalog, viral marketing pipelines, and live Firebase cloud integration.

## Features
- **Landing Page**: Conversion-engineered with 3D interactive flip cards, wholesale economics calculator, milestone progression roadmap, and authentic leadership profile.
- **Partner System**: 4 Rank Milestones (Silver, Platinum, Gold, Diamond) with automated volume and community tracking.
- **Authentication & Cloud Backend**: Firebase Authentication, Firestore, and Realtime Database.
- **Product Distribution**: Wholesale vs Retail margin calculation, order logging, and referral attribution engine.

## Tech Stack
- React 19 + TypeScript + Vite
- Tailwind CSS v4
- Firebase (Auth, Firestore, RTDB, Storage)
- Phosphor Icons & GSAP animations

## Getting Started

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build
```
